## 빈칸
- 지원사업명: 예) 2027년 예비창업패키지
- 양식: 예) 공고에 있는 양식 파일을 첨부함 / 양식 없음
- 아이템: 예) 동네 요가원용 수업 예약 서비스
- 지금까지 한 것: 예) 원장 12명 인터뷰, 시제품으로 요가원 2곳 한 달 시험 운영

## 왜 이렇게 썼나
- "숫자를 지어내지 마", "양식을 지키라", "출처를 붙여" 같은 조건은 적지 않았습니다. 지침 8번에 있습니다.
- 제출처와 양식은 지침 8번이 시작 전에 묻는 것이라, 미리 적어 질문 한 번을 줄였습니다.
- 지금까지 한 것을 적게 했습니다. 지침 8번은 사용자가 알려준 사실로만 쓰기 때문에, 알려주지 않으면 실적 칸이 '확인 필요'로 남습니다.

## 기대 응답
- 양식이 있으면 칸과 순서를 그대로 지키고, 없으면 PSST 순서로 씁니다.
- 알려주지 않은 실적, 수치, 경력은 지어내지 않고 '확인 필요'로 표시합니다.
- 아이템명이나 개발 배경 같은 문장은 후보를 여러 개 줍니다.
- AI가 제안한 전략에는 '제안'이라고 표시하고, 채우지 못한 칸에 무엇이 더 필요한지 목록으로 알려줍니다.

## 실패 신호
- 고객 반응이나 매출을 그럴듯하게 지어냅니다.
- 화면 목록이나 기술 스택이 들어간 개발용 기획서를 씁니다.
- 양식의 칸을 지우거나 순서를 바꿉니다.

## 이어서 쓰는 문장
- '확인 필요'로 표시한 곳을 채우려면 내가 무엇을 준비해야 하는지 급한 순서로 정리해줘.
- 본문에 맞춰 서두(요약)를 다시 써줘.
